# Helix v1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CRM local de prospecção que busca estabelecimentos na Google Places API, classifica quem não tem site próprio, e acompanha o contato num funil customizável.

**Architecture:** Next.js App Router como processo único. Todo o domínio vive em `lib/` como TypeScript puro sem dependência de framework — `app/api/` é casca fina sobre `lib/services/`, e o servidor MCP da fase 2 importará os mesmos serviços. Persistência em SQLite via Drizzle.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, Drizzle ORM, better-sqlite3, Vitest, Testing Library, `@vis.gl/react-google-maps`.

**Spec:** `docs/superpowers/specs/2026-09-06-helix-crm-design.md`

## Global Constraints

- Node.js 20+ (`better-sqlite3` precisa de build nativo compatível).
- Usuário único, localhost. **Nenhuma autenticação, nenhum controle de acesso, nenhum deploy.**
- Todo domínio em `lib/`. `app/api/` e (futuro) `mcp/` não contêm regra de negócio.
- Datas gravadas como TEXT ISO-8601 UTC (`new Date().toISOString()`).
- `PRAGMA foreign_keys = ON` e `PRAGMA journal_mode = WAL` em toda conexão.
- Três blocos de dados em `leads` com donos distintos: **Google** (só escrito pela ingestão), **usuário** (só escrito pela UI), **IA** (v2, tabela separada). Nenhum sobrescreve o outro.
- Nenhum hard delete de lead. `verification = 'descartado'` é estado.
- Identidade visual do mockup em `../mockup-helix`: preto `#0a0a0a` sobre off-white `#fbfbf9`, DM Mono nos rótulos, Inter no corpo, bordas 1px, `border-radius: 0`.
- Textos de interface em português do Brasil.
- Temperatura é sempre um de: `quente` | `morno` | `frio`.
- Verificação é sempre um de: `pendente` | `qualificado` | `descartado`.
- `stages.kind` é sempre um de: `open` | `won` | `lost`.
- Places API: field mask fixo definido na Task 5. Máximo 3 páginas por busca.

```ts
export interface HelixEnv {
  googlePlacesKey: string;
  googleMapsBrowserKey: string;
  databaseUrl: string;
}

type RawEnv = Record<string, string | undefined>;

function required(raw: RawEnv, key: string): string {
  const value = raw[key];
  if (!value || value.trim() === '') {
    throw new Error(
      `Variável de ambiente ${key} não definida. Copie .env.example para .env e preencha.`,
    );
  }
  return value;
}

export function readEnv(raw: RawEnv): HelixEnv {
  return {
    googlePlacesKey: required(raw, 'GOOGLE_PLACES_KEY'),
    googleMapsBrowserKey: required(raw, 'NEXT_PUBLIC_GOOGLE_MAPS_KEY'),
    databaseUrl: raw.DATABASE_URL?.trim() || './helix.db',
  };
}

export function getEnv(): HelixEnv {
  return readEnv(process.env);
}
```

```ts
import Database from 'better-sqlite3';
import { drizzle, type BetterSQLite3Database } from 'drizzle-orm/better-sqlite3';
import { migrate } from 'drizzle-orm/better-sqlite3/migrator';
import path from 'node:path';
import * as schema from './schema';

export type HelixDb = BetterSQLite3Database<typeof schema>;

const MIGRATIONS_FOLDER = path.join(process.cwd(), 'lib/db/migrations');

function applyPragmas(sqlite: Database.Database) {
  sqlite.pragma('foreign_keys = ON');
  sqlite.pragma('journal_mode = WAL');
}

let cached: HelixDb | null = null;

export function getDb(): HelixDb {
  if (cached) return cached;
  const url = process.env.DATABASE_URL?.trim() || './helix.db';
  const sqlite = new Database(url);
  applyPragmas(sqlite);
  cached = drizzle(sqlite, { schema });
  return cached;
}

/** Banco em memória, já migrado. Uso exclusivo de teste. */
export function createTestDb(): { db: HelixDb; close: () => void } {
  const sqlite = new Database(':memory:');
  sqlite.pragma('foreign_keys = ON');
  const db = drizzle(sqlite, { schema });
  migrate(db, { migrationsFolder: MIGRATIONS_FOLDER });
  return { db, close: () => sqlite.close() };
}
```

`journal_mode = WAL` não é aplicado ao banco em memória porque não há arquivo — daí os pragmas separados em `createTestDb`.

```ts
import type { HelixDb } from './client';
import { stages, DEFAULT_STAGES } from './schema';

/** Grava o funil padrão. Não faz nada se já houver etapas. */
export function seedStages(db: HelixDb): void {
  const existing = db.select().from(stages).all();
  if (existing.length > 0) return;
```

```ts
import { DOMAIN_GROUPS, type DomainGroups } from '@/config/domains';
import type { Temperature } from '@/lib/db/schema';

export function extractHost(uri: string | null | undefined): string | null {
  if (!uri) return null;
  const trimmed = uri.trim();
  if (trimmed === '') return null;

  const withProtocol = /^https?:\/\//i.test(trimmed) ? trimmed : `https://${trimmed}`;
  let host: string;
  try {
    host = new URL(withProtocol).hostname.toLowerCase();
  } catch {
    return null;
  }
  if (!host.includes('.')) return null;
  return host.replace(/^www\./, '');
}

function matchesDomain(host: string, domain: string): boolean {
  return host === domain || host.endsWith(`.${domain}`);
}

/**
 * quente = sem site       → alvo da prospecção
 * morno  = social/marketplace → tem canal, não tem site
 * frio   = site próprio   → insumo da auditoria da v2
 */
export function classify(
  websiteUri: string | null | undefined,
  groups: DomainGroups = DOMAIN_GROUPS,
): Temperature {
  const host = extractHost(websiteUri);
  if (host === null) return 'quente';

  const known = [...groups.social, ...groups.marketplace];
  if (known.some((domain) => matchesDomain(host, domain))) return 'morno';

  return 'frio';
}
```

```ts
import { classify } from '@/lib/classify/temperature';
import type { NormalizedPlace, PlaceRaw } from './types';

function orNull<T>(value: T | undefined): T | null {
  return value === undefined ? null : value;
}

/** Devolve null para resultados sem id ou sem nome — sem eles o lead é inútil. */
export function normalize(raw: PlaceRaw): NormalizedPlace | null {
  const placeId = raw.id?.trim();
  const name = raw.displayName?.text?.trim();
  if (!placeId || !name) return null;

  const websiteUri = orNull(raw.websiteUri);

  return {
    placeId,
    name,
    formattedAddress: orNull(raw.formattedAddress),
    lat: orNull(raw.location?.latitude),
    lng: orNull(raw.location?.longitude),
    phone: orNull(raw.nationalPhoneNumber),
    websiteUri,
    rating: orNull(raw.rating),
    userRatingCount: orNull(raw.userRatingCount),
    businessStatus: orNull(raw.businessStatus),
    primaryType: orNull(raw.primaryType),
    primaryTypeDisplay: orNull(raw.primaryTypeDisplayName?.text),
    googleMapsUri: orNull(raw.googleMapsUri),
    rawJson: JSON.stringify(raw),
    temperature: classify(websiteUri),
  };
}
```

```ts
import type { PlaceRaw, SearchTextResponse } from './types';

const ENDPOINT = 'https://places.googleapis.com/v1/places:searchText';

/**
 * A cobrança segue o tier mais caro pedido. websiteUri e nationalPhoneNumber
 * já colocam a chamada em Enterprise, então places.id (Essentials) e
 * places.location (Pro) entram sem custo extra.
 * nextPageToken é campo de resposta, não é cobrado, e fica explícito
 * para não haver dúvida sobre a paginação.
 */
export const PLACES_FIELD_MASK = [
  'places.id',
  'places.displayName',
  'places.formattedAddress',
  'places.location',
  'places.nationalPhoneNumber',
  'places.websiteUri',
  'places.rating',
  'places.userRatingCount',
  'places.businessStatus',
  'places.primaryType',
  'places.primaryTypeDisplayName',
  'places.googleMapsUri',
  'nextPageToken',
].join(',');

/** Limite duro da API: 20 por página, 3 páginas, 60 resultados. */
export const MAX_PAGES = 3;
export const PAGE_SIZE = 20;
const PAGE_DELAY_MS = 500;

export interface PlacesQuery {
  textQuery: string;
  includedType?: string | null;
  minRating?: number | null;
  maxPages?: number;
}

export interface PlacesFetchResult {
  places: PlaceRaw[];
  pagesFetched: number;
  apiRequests: number;
}

export interface PlacesDeps {
  apiKey: string;
  fetchFn?: typeof fetch;
  sleep?: (ms: number) => Promise<void>;
}

export function buildRequestBody(
  query: PlacesQuery,
  pageToken?: string,
): Record<string, unknown> {
  const body: Record<string, unknown> = {
    textQuery: query.textQuery,
    pageSize: PAGE_SIZE,
    languageCode: 'pt-BR',
    regionCode: 'BR',
  };

  if (query.includedType) {
    body.includedType = query.includedType;
    body.strictTypeFiltering = true;
  }
  if (typeof query.minRating === 'number') {
    body.minRating = query.minRating;
  }
  if (pageToken) {
    body.pageToken = pageToken;
  }
  return body;
}

const defaultSleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms));

export async function fetchPlaces(
  query: PlacesQuery,
  deps: PlacesDeps,
): Promise<PlacesFetchResult> {
  const doFetch = deps.fetchFn ?? fetch;
  const sleep = deps.sleep ?? defaultSleep;
  const limit = Math.min(query.maxPages ?? MAX_PAGES, MAX_PAGES);

  const places: PlaceRaw[] = [];
  let pageToken: string | undefined;
  let apiRequests = 0;
  let pagesFetched = 0;

  for (let page = 0; page < limit; page++) {
    const res = await doFetch(ENDPOINT, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-Goog-Api-Key': deps.apiKey,
        'X-Goog-FieldMask': PLACES_FIELD_MASK,
      },
      body: JSON.stringify(buildRequestBody(query, pageToken)),
    });
    apiRequests++;

    if (!res.ok) {
      const detail = await res.text();
      throw new Error(`Places API respondeu ${res.status}: ${detail}`);
    }

    const data = (await res.json()) as SearchTextResponse;
    places.push(...(data.places ?? []));
    pagesFetched++;

    if (!data.nextPageToken) break;
    pageToken = data.nextPageToken;

    if (page + 1 < limit) await sleep(PAGE_DELAY_MS);
  }

  return { places, pagesFetched, apiRequests };
}
```

```ts
import { leads, stages } from '@/lib/db/schema';
import type { NormalizedPlace } from '@/lib/places/types';

export interface UpsertOutcome {
  leadId: number;
  wasNew: boolean;
}

function firstStageId(db: HelixDb): number | null {
  const first = db.select().from(stages).orderBy(asc(stages.position)).limit(1).get();
  return first?.id ?? null;

/**
 * Insere ou atualiza um lead pelo place_id.
 *
 * Atualiza APENAS o bloco do Google. verification, stageId, notes, contatos e
 * next_action pertencem ao usuário e nunca são tocados aqui — sem isso, todo
 * re-scan obrigaria a re-avaliar trabalho já feito.
 */
export function upsertPlace(
  db: HelixDb,
  place: NormalizedPlace,
  now: string,
): UpsertOutcome {
  const existing = db.select({ id: leads.id })
    .from(leads)
    .where(eq(leads.placeId, place.placeId))
    .get();

  const googleBlock = {
    name: place.name,
    formattedAddress: place.formattedAddress,
    lat: place.lat,
    lng: place.lng,
    phone: place.phone,
    websiteUri: place.websiteUri,
    rating: place.rating,
    userRatingCount: place.userRatingCount,
    businessStatus: place.businessStatus,
    primaryType: place.primaryType,
    primaryTypeDisplay: place.primaryTypeDisplay,
    googleMapsUri: place.googleMapsUri,
    rawJson: place.rawJson,
    capturedAt: now,
    temperature: place.temperature,
    updatedAt: now,
  };

  if (existing) {
    db.update(leads).set(googleBlock).where(eq(leads.id, existing.id)).run();
    return { leadId: existing.id, wasNew: false };
  }

  const inserted = db.insert(leads).values({
    placeId: place.placeId,
    ...googleBlock,
    stageId: firstStageId(db),
    verification: 'pendente',
    createdAt: now,
  }).returning({ id: leads.id }).get();

  return { leadId: inserted.id, wasNew: true };
}

export function upsertPlaces(
  db: HelixDb,
  places: NormalizedPlace[],
  now: string,
): UpsertOutcome[] {
  return places.map((place) => upsertPlace(db, place, now));
```

```ts
import { eq, inArray } from 'drizzle-orm';
import type { HelixDb } from '@/lib/db/client';
import { leads, leadSearches, searches, type Lead, type Temperature } from '@/lib/db/schema';
import { fetchPlaces, type PlacesDeps } from '@/lib/places/client';
import { normalize } from '@/lib/places/normalize';
import { upsertPlaces } from '@/lib/repo/leads';

export interface ClientFilters {
  temperatures?: Temperature[];
  requirePhone?: boolean;
  minReviews?: number | null;
  maxReviews?: number | null;
  excludeClosed?: boolean;
}

export interface RunSearchInput {
  textQuery: string;
  includedType?: string | null;
  minRating?: number | null;
  maxPages?: number;
  filters?: ClientFilters;
  presetId?: number | null;
}

export interface RunSearchResult {
  searchId: number;
  rawCount: number;
  newCount: number;
  apiRequests: number;
  pagesFetched: number;
  leadIds: number[];
}

export type RunSearchDeps = PlacesDeps & { now?: () => string };

/**
 * Filtros client-side. Rodam DEPOIS da gravação — os 60 resultados entram no
 * banco de qualquer forma, o filtro só decide o que a tela mostra.
 */
export function applyClientFilters(rows: Lead[], filters: ClientFilters): Lead[] {
  return rows.filter((row) => {
    if (filters.temperatures?.length && !filters.temperatures.includes(row.temperature)) {
      return false;
    }
    if (filters.requirePhone && !row.phone) return false;

    const reviews = row.userRatingCount ?? 0;
    if (typeof filters.minReviews === 'number' && reviews < filters.minReviews) return false;
    if (typeof filters.maxReviews === 'number' && reviews > filters.maxReviews) return false;

    if (filters.excludeClosed && row.businessStatus === 'CLOSED_PERMANENTLY') return false;

    return true;
  });
}

export async function runSearch(
  db: HelixDb,
  input: RunSearchInput,
  deps: RunSearchDeps,
): Promise<RunSearchResult> {
  const now = deps.now?.() ?? new Date().toISOString();
  const filters = input.filters ?? {};

  // A busca é gravada antes da chamada para que a falha também fique registrada.
  const search = db.insert(searches).values({
    presetId: input.presetId ?? null,
    textQuery: input.textQuery,
    includedType: input.includedType ?? null,
    minRating: input.minRating ?? null,
    filtersJson: JSON.stringify(filters),
    executedAt: now,
  }).returning({ id: searches.id }).get();

  let fetched;
  try {
    fetched = await fetchPlaces(
      {
        textQuery: input.textQuery,
        includedType: input.includedType,
        minRating: input.minRating,
        maxPages: input.maxPages,
      },
      deps,
    );
  } catch (error) {
    const message = error instanceof Error ? error.message : String(error);
    db.update(searches).set({ error: message })
      .where(eq(searches.id, search.id)).run();
    throw error;
  }

  const normalized = fetched.places
    .map(normalize)
    .filter((p): p is NonNullable<typeof p> => p !== null);

  const outcomes = upsertPlaces(db, normalized, now);
  const newCount = outcomes.filter((o) => o.wasNew).length;

  if (outcomes.length > 0) {
    // Um place_id repetido no mesmo lote gera o mesmo leadId duas vezes;
    // a chave composta de lead_searches não aceita duplicata.
    const seen = new Set<number>();
    const joinRows = outcomes.filter((o) => {
      if (seen.has(o.leadId)) return false;
      seen.add(o.leadId);
      return true;
    }).map((o) => ({ leadId: o.leadId, searchId: search.id, wasNew: o.wasNew }));

    db.insert(leadSearches).values(joinRows).run();
  }

  db.update(searches).set({
    pagesFetched: fetched.pagesFetched,
    apiRequests: fetched.apiRequests,
    rawCount: normalized.length,
    newCount,
  }).where(eq(searches.id, search.id)).run();

  const leadIds = outcomes.map((o) => o.leadId);
  const rows = leadIds.length
    ? db.select().from(leads).where(inArray(leads.id, leadIds)).all()
    : [];

  return {
    searchId: search.id,
    rawCount: normalized.length,
    newCount,
    apiRequests: fetched.apiRequests,
    pagesFetched: fetched.pagesFetched,
    leadIds: applyClientFilters(rows, filters).map((r) => r.id),
  };
}
```

```ts
export interface ListLeadsInput {
  temperatures?: Temperature[];
  verifications?: Verification[];
  stageId?: number | null;
  search?: string | null;
  limit?: number;
  offset?: number;
}

export interface ListLeadsResult {
  rows: Lead[];
  total: number;
}

/** A lista abre no que interessa: quente e ainda vivo. */
export const DEFAULT_LIST_INPUT: ListLeadsInput = {
  temperatures: ['quente'],
  verifications: ['pendente', 'qualificado'],
};

function listConditions(input: ListLeadsInput): SQL[] {
  const parts: SQL[] = [];

  if (input.temperatures?.length) {
    parts.push(inArray(leads.temperature, input.temperatures));
  }
  if (input.verifications?.length) {
    parts.push(inArray(leads.verification, input.verifications));
  }
  if (typeof input.stageId === 'number') {
    parts.push(eq(leads.stageId, input.stageId));
  }
  const term = input.search?.trim();
  if (term) {
    const pattern = `%${term.toLowerCase()}%`;
    parts.push(
      or(
        like(sql`lower(${leads.name})`, pattern),
        like(sql`lower(coalesce(${leads.formattedAddress}, ''))`, pattern),
        like(sql`lower(coalesce(${leads.notes}, ''))`, pattern),
      )!,
    );
  }
  return parts;
}

export function listLeads(db: HelixDb, input: ListLeadsInput): ListLeadsResult {
  const parts = listConditions(input);
  const where = parts.length ? and(...parts) : undefined;

  const total = db.select({ value: count() }).from(leads).where(where).get()?.value ?? 0;

  const rows = db.select().from(leads)
    .where(where)
    .orderBy(desc(leads.updatedAt), desc(leads.id))
    .limit(input.limit ?? 50)
    .offset(input.offset ?? 0)
    .all();

  return { rows, total };
}
```

```ts
import type { HelixDb } from '@/lib/db/client';
import { leads, stages, type Stage, type StageKind } from '@/lib/db/schema';

export function listStages(db: HelixDb): Stage[] {
  return db.select().from(stages).orderBy(asc(stages.position)).all();
}

export function getStage(db: HelixDb, id: number): Stage | null {
  return db.select().from(stages).where(eq(stages.id, id)).get() ?? null;
}

export function createStage(
  db: HelixDb,
  input: { name: string; kind?: StageKind; color?: string | null },
): Stage {
  const last = listStages(db).at(-1);
  return db.insert(stages).values({
    name: input.name,
    kind: input.kind ?? 'open',
    color: input.color ?? null,
    position: (last?.position ?? 0) + 1,
  }).returning().get();
}

export function renameStage(db: HelixDb, id: number, name: string): Stage {
  const current = getStage(db, id);
  if (!current) throw new Error(`Etapa ${id} não encontrada.`);
  db.update(stages).set({ name }).where(eq(stages.id, id)).run();
  return getStage(db, id)!;
}

export function reorderStages(db: HelixDb, orderedIds: number[]): Stage[] {
  orderedIds.forEach((id, index) => {
    db.update(stages).set({ position: index + 1 }).where(eq(stages.id, id)).run();
  });
  return listStages(db);
}

/**
 * Excluir etapa exige destino para os leads que estavam nela.
 * Sem cascade e sem órfão — um lead sempre pertence a alguma etapa.
 */
export function deleteStage(db: HelixDb, id: number, moveLeadsTo: number): void {
  if (id === moveLeadsTo) {
    throw new Error('Não é possível mover os leads para a mesma etapa que será excluída.');
  }
  const current = getStage(db, id);
  if (!current) throw new Error(`Etapa ${id} não encontrada.`);

  const destination = getStage(db, moveLeadsTo);
  if (!destination) throw new Error(`Etapa de destino ${moveLeadsTo} não encontrada.`);

  if (listStages(db).length <= 1) {
    throw new Error('O funil precisa de pelo menos uma etapa.');
  }

  db.update(leads).set({ stageId: moveLeadsTo }).where(eq(leads.stageId, id)).run();
  db.delete(stages).where(eq(stages.id, id)).run();

  listStages(db).forEach((stage, index) => {
    db.update(stages).set({ position: index + 1 }).where(eq(stages.id, stage.id)).run();
  });
}
```

```ts
import type { HelixDb } from '@/lib/db/client';
import type { Lead } from '@/lib/db/schema';
import { addActivity } from '@/lib/repo/activities';
import { getLead, updateUserBlock } from '@/lib/repo/leads';

/** Move o lead e registra a mudança na timeline automaticamente. */
export function moveLeadToStage(
  db: HelixDb,
  leadId: number,
  stageId: number,
  now: string,
): Lead {
  const lead = getLead(db, leadId);
  if (!lead) throw new Error(`Lead ${leadId} não encontrado.`);

  const destination = getStage(db, stageId);
  if (!destination) throw new Error(`Etapa ${stageId} não encontrada.`);

  if (lead.stageId === stageId) return lead;

  const origin = lead.stageId ? getStage(db, lead.stageId) : null;
  const updated = updateUserBlock(db, leadId, { stageId }, now);

  addActivity(db, {
    leadId,
    kind: 'stage_change',
    body: `${origin?.name ?? 'Sem etapa'} → ${destination.name}`,
  }, now);

  return updated;
}
```

```ts
export function jsonOk<T>(data: T): Response {
  return Response.json(data as unknown as Record<string, unknown>, { status: 200 });
}

export function jsonError(message: string, status: number): Response {
  return Response.json({ error: message }, { status });
}

export async function handle<T>(fn: () => T | Promise<T>): Promise<Response> {
  try {
    return jsonOk(await fn());
  } catch (error) {
    const message = error instanceof Error ? error.message : String(error);
    const status = /não encontrad/i.test(message) ? 404 : 400;
    return jsonError(message, status);
  }
}
```

```ts
async function parse<T>(res: Response): Promise<T> {
  const body = await res.json().catch(() => ({}));
  if (!res.ok) {
    throw new Error((body as { error?: string }).error ?? `Erro ${res.status}`);
  }
  return body as T;
}

export async function apiGet<T>(path: string): Promise<T> {
  return parse<T>(await fetch(path, { cache: 'no-store' }));
}

export async function apiSend<T>(
  path: string,
  method: 'POST' | 'PATCH' | 'PUT' | 'DELETE',
  body?: unknown,
): Promise<T> {
  return parse<T>(await fetch(path, {
    method,
    headers: body ? { 'Content-Type': 'application/json' } : undefined,
    body: body ? JSON.stringify(body) : undefined,
  }));
}
```

```tsx
'use client';

import { useCallback, useEffect, useState } from 'react';
import type { Activity, ActivityKind, Lead, Stage, Temperature } from '@/lib/db/schema';
import type { UserBlockPatch } from '@/lib/repo/leads';
import { apiGet, apiSend } from '@/lib/api/client';
import { LeadTable } from './LeadTable';
import { LeadDetail } from './LeadDetail';

const TEMPERATURAS: Temperature[] = ['quente', 'morno', 'frio'];

export function LeadsView() {
  const [temperatures, setTemperatures] = useState<Temperature[]>(['quente']);
  const [incluirDescartados, setIncluirDescartados] = useState(false);
  const [busca, setBusca] = useState('');
  const [rows, setRows] = useState<Lead[]>([]);
  const [total, setTotal] = useState(0);
  const [stages, setStages] = useState<Stage[]>([]);
  const [selectedId, setSelectedId] = useState<number | null>(null);
  const [detail, setDetail] = useState<{ lead: Lead; activities: Activity[] } | null>(null);
  const [erro, setErro] = useState<string | null>(null);

  const carregarLista = useCallback(async () => {
    const params = new URLSearchParams();
    params.set('temperatures', temperatures.join(','));
    params.set('verifications', incluirDescartados
      ? 'pendente,qualificado,descartado'
      : 'pendente,qualificado');
    if (busca.trim()) params.set('search', busca.trim());

    try {
      const out = await apiGet<{ rows: Lead[]; total: number }>(`/api/leads?${params}`);
      setRows(out.rows);
      setTotal(out.total);
      setErro(null);
    } catch (e) {
      setErro(e instanceof Error ? e.message : String(e));
    }
  }, [temperatures, incluirDescartados, busca]);

  const carregarDetalhe = useCallback(async (id: number) => {
    setDetail(await apiGet<{ lead: Lead; activities: Activity[] }>(`/api/leads/${id}`));
  }, []);

  useEffect(() => { void carregarLista(); }, [carregarLista]);
  useEffect(() => { void apiGet<Stage[]>('/api/stages').then(setStages); }, []);
  useEffect(() => {
    if (selectedId === null) setDetail(null);
    else void carregarDetalhe(selectedId);
  }, [selectedId, carregarDetalhe]);

  async function patch(body: UserBlockPatch) {
    if (selectedId === null) return;
    await apiSend(`/api/leads/${selectedId}`, 'PATCH', body);
    await carregarDetalhe(selectedId);
    await carregarLista();
  }

  async function addActivity(input: { kind: ActivityKind; body: string }) {
    if (selectedId === null) return;
    await apiSend(`/api/leads/${selectedId}/activities`, 'POST', input);
    await carregarDetalhe(selectedId);
  }

  function toggleTemperature(t: Temperature) {
    setTemperatures((prev) =>
      prev.includes(t) ? prev.filter((x) => x !== t) : [...prev, t],
    );
  }

  return (
    <div className="view">
      <span className="mono">Base comercial</span>
      <h1>Leads</h1>

      {erro && <p className="error">{erro}</p>}

      <div style={{ margin: '24px 0', display: 'flex', gap: 16, alignItems: 'center', flexWrap: 'wrap' }}>
        {TEMPERATURAS.map((t) => (
          <label key={t} style={{ display: 'flex', gap: 6, fontSize: 12 }}>
            <input
              type="checkbox"
              checked={temperatures.includes(t)}
              onChange={() => toggleTemperature(t)}
            />
            {t}
          </label>
        ))}
        <label style={{ display: 'flex', gap: 6, fontSize: 12 }}>
          <input
            type="checkbox"
            checked={incluirDescartados}
            onChange={(e) => setIncluirDescartados(e.target.checked)}
          />
          incluir descartados
        </label>
        <input
          placeholder="Buscar por nome, endereço ou nota…"
          value={busca}
          onChange={(e) => setBusca(e.target.value)}
          style={{ height: 38, padding: '0 10px', border: '1px solid var(--line)', minWidth: 280 }}
        />
        <span className="mono">{total} leads</span>
      </div>

      <div style={{ display: 'grid', gridTemplateColumns: detail ? '1fr 420px' : '1fr', gap: 24 }}>
        <div className="panel">
          <LeadTable rows={rows} selectedId={selectedId} onSelect={setSelectedId} />
        </div>

        {detail && (
          <div>
            <button
              className="btn btn-outline"
              style={{ marginBottom: 16 }}
              onClick={() => setSelectedId(null)}
            >
              Fechar
            </button>
            <LeadDetail
              lead={detail.lead}
              activities={detail.activities}
              stages={stages}
              onPatch={patch}
              onAddActivity={addActivity}
            />
          </div>
        )}
      </div>
    </div>
  );
}
```

```ts
'use client';

import { useMemo, useState } from 'react';
import type { Lead } from '@/lib/db/schema';

export interface LatLng {
  lat: number;
  lng: number;
}

export const SAO_PAULO: LatLng = { lat: -23.5505, lng: -46.6333 };

export function useSelection(rows: Lead[]) {
  const [selectedId, setSelectedId] = useState<number | null>(null);

  const selected = useMemo(
    () => rows.find((row) => row.id === selectedId) ?? null,
    [rows, selectedId],
  );

  const center = useMemo<LatLng>(() => {
    if (selected?.lat != null && selected.lng != null) {
      return { lat: selected.lat, lng: selected.lng };
    }
    const comCoordenada = rows.filter(
      (row): row is Lead & { lat: number; lng: number } =>
        row.lat != null && row.lng != null,
    );
    if (comCoordenada.length === 0) return SAO_PAULO;

    const soma = comCoordenada.reduce(
      (acc, row) => ({ lat: acc.lat + row.lat, lng: acc.lng + row.lng }),
      { lat: 0, lng: 0 },
    );
    return {
      lat: soma.lat / comCoordenada.length,
      lng: soma.lng / comCoordenada.length,
    };
  }, [rows, selected]);

  return { selectedId, select: setSelectedId, selected, center };
}
```

```ts
import type { Lead, Stage } from '@/lib/db/schema';

export interface StageColumn {
  stage: Stage;
  leads: Lead[];
}

/** Toda etapa vira coluna, mesmo vazia. Lead órfão cai na primeira. */
export function groupByStage(stages: Stage[], rows: Lead[]): StageColumn[] {
  if (stages.length === 0) return [];

  const ordered = [...stages].sort((a, b) => a.position - b.position);
  const known = new Set(ordered.map((s) => s.id));
  const columns = new Map<number, Lead[]>(ordered.map((s) => [s.id, []]));
  const fallback = ordered[0].id;

  for (const row of rows) {
    const target = row.stageId != null && known.has(row.stageId) ? row.stageId : fallback;
    columns.get(target)!.push(row);
  }

  return ordered.map((stage) => ({ stage, leads: columns.get(stage.id)! }));
}
```

```tsx
'use client';

import { useCallback, useEffect, useState } from 'react';
import type { Stage, StageKind } from '@/lib/db/schema';
import { apiGet, apiSend } from '@/lib/api/client';

export function StagesView() {
  const [stages, setStages] = useState<Stage[]>([]);
  const [nome, setNome] = useState('');
  const [kind, setKind] = useState<StageKind>('open');
  const [erro, setErro] = useState<string | null>(null);

  const carregar = useCallback(async () => {
    setStages(await apiGet<Stage[]>('/api/stages'));
  }, []);

  useEffect(() => { void carregar(); }, [carregar]);

  async function executar(acao: () => Promise<unknown>) {
    try {
      await acao();
      await carregar();
      setErro(null);
    } catch (e) {
      setErro(e instanceof Error ? e.message : String(e));
    }
  }

  function mover(index: number, delta: number) {
    const alvo = index + delta;
    if (alvo < 0 || alvo >= stages.length) return;
    const ids = stages.map((s) => s.id);
    [ids[index], ids[alvo]] = [ids[alvo], ids[index]];
    void executar(() => apiSend('/api/stages', 'PUT', { orderedIds: ids }));
  }

  function excluir(stage: Stage) {
    const destino = stages.find((s) => s.id !== stage.id);
    if (!destino) {
      setErro('O funil precisa de pelo menos uma etapa.');
      return;
    }
    void executar(() =>
      apiSend(`/api/stages/${stage.id}?moveLeadsTo=${destino.id}`, 'DELETE'),
    );
  }

  return (
    <div className="view">
      <span className="mono">Configuração</span>
      <h1>Etapas do funil</h1>

      {erro && <p className="error" style={{ marginTop: 16 }}>{erro}</p>}

      <div className="panel" style={{ marginTop: 24 }}>
        <table>
          <thead>
            <tr><th>Ordem</th><th>Nome</th><th>Tipo</th><th></th></tr>
          </thead>
          <tbody>
            {stages.map((stage, index) => (
              <tr key={stage.id}>
                <td>{stage.position}</td>
                <td>
                  <input
                    defaultValue={stage.name}
                    onBlur={(e) => {
                      if (e.target.value.trim() && e.target.value !== stage.name) {
                        void executar(() =>
                          apiSend(`/api/stages/${stage.id}`, 'PATCH',
                            { name: e.target.value.trim() }),
                        );
                      }
                    }}
                    style={{ border: '1px solid var(--line)', padding: '4px 8px' }}
                  />
                </td>
                <td className="mono">{stage.kind}</td>
                <td style={{ display: 'flex', gap: 6 }}>
                  <button className="btn btn-outline" onClick={() => mover(index, -1)}>↑</button>
                  <button className="btn btn-outline" onClick={() => mover(index, 1)}>↓</button>
                  <button className="btn btn-outline" onClick={() => excluir(stage)}>
                    Excluir
                  </button>
                </td>
              </tr>
            ))}
          </tbody>
        </table>
      </div>

      <div style={{ marginTop: 24, display: 'flex', gap: 12, alignItems: 'flex-end' }}>
        <label className="field">
          <span className="mono">Nova etapa</span>
          <input value={nome} onChange={(e) => setNome(e.target.value)} />
        </label>
        <label className="field">
          <span className="mono">Tipo</span>
          <select value={kind} onChange={(e) => setKind(e.target.value as StageKind)}>
            <option value="open">Aberta</option>
            <option value="won">Ganho</option>
            <option value="lost">Perdido</option>
          </select>
        </label>
        <button
          className="btn"
          disabled={!nome.trim()}
          onClick={() => void executar(async () => {
            await apiSend('/api/stages', 'POST', { name: nome.trim(), kind });
            setNome('');
          })}
        >
          Adicionar
        </button>
      </div>

      <p style={{ marginTop: 16, fontSize: 11, color: 'var(--muted)' }}>
        Ao excluir uma etapa, os leads dela são movidos para a primeira etapa
        restante — nenhum lead fica órfão.
      </p>
    </div>
  );
}
```

```ts
import type { Lead } from '@/lib/db/schema';

export const CSV_HEADER = [
  'nome', 'tipo', 'endereco', 'telefone', 'site', 'temperatura',
  'avaliacao', 'qtd_avaliacoes', 'situacao', 'verificacao', 'motivo_descarte',
  'contato', 'email', 'instagram', 'whatsapp', 'proxima_acao', 'quando',
  'notas', 'google_maps', 'capturado_em',
] as const;

function cell(value: unknown): string {
  if (value === null || value === undefined) return '""';
  return `"${String(value).replace(/"/g, '""')}"`;
}

export function toCsv(rows: Lead[]): string {
  const header = CSV_HEADER.map((h) => `"${h}"`).join(',');

  const lines = rows.map((row) => [
    row.name, row.primaryTypeDisplay, row.formattedAddress, row.phone,
    row.websiteUri, row.temperature, row.rating, row.userRatingCount,
    row.businessStatus, row.verification, row.disqualifyReason,
    row.contactName, row.email, row.instagram, row.whatsapp,
    row.nextAction, row.nextActionAt, row.notes, row.googleMapsUri,
    row.capturedAt,
  ].map(cell).join(','));

  return [header, ...lines].join('\n');
}
```

# Helix

CRM local de prospecção geográfica. Busca estabelecimentos na Google Places
API, classifica quem não tem site próprio, e acompanha o contato num funil
customizável.

Usuário único, roda em localhost. Sem autenticação e sem deploy.

```bash
npm install
cp .env.example .env    # preencher as duas chaves do Google
npm run db:migrate
```

## Temperatura

| | Significado | Uso |
|---|---|---|
| `quente` | sem site nenhum | alvo da prospecção |
| `morno` | só Instagram, Facebook, iFood, Doctoralia… | tem canal, não tem site |
| `frio` | site próprio | insumo da auditoria da v2 |

A lista de domínios que definem `morno` está em `config/domains.ts` e é
livre para editar.

## Limites da Places API

Uma busca é uma query de texto: 20 resultados por página, no máximo 3
páginas, teto de 60 por query. Para ir além, rode outra query — outro
bairro, outro termo.

Cada página é uma chamada cobrada. O volume de uso pessoal fica dentro da
cota mensal gratuita. Para garantir, defina um teto em
**Google Cloud Console → APIs & Services → Places API → Quotas**.

## Regras que o app garante

- Todos os resultados são gravados, inclusive os frios
- Re-busca atualiza o bloco do Google e nunca toca no seu trabalho manual
- Lead descartado continua descartado depois de um novo scan
- Nenhum lead é apagado — descarte é estado
